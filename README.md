# HUD — High-Signal Personal News Feed

A heads-up display for the internet: an auto-scrolling, ranked news feed that
mixes your focus areas with what's breaking. Built for the Open HUD Challenge.

**▶ Live:** https://hud-news.vercel.app — sign in as **guest** to try instantly.

The app and its modular AI/ML pipeline live in **[`web/`](./web)** (Next.js 16 +
Convex + TypeScript, deployed on Vercel).
